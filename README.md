# StarCraft II Marine Growth

스타크래프트 II 아케이드용 해병 성장 게임의 기획·조사 저장소입니다. 이 저장소는 게임 방향을 함께 정하는 문서 중심의 공개 리포지토리입니다. 확정되지 않은 설계는 제안이나 조사 항목으로 표시하고, 합의된 결정만 결정 기록에 반영합니다.

## 현재 기획 방향

- 핵심 캐릭터는 해병 한 명이며, 계급은 여러 성장 축 가운데 큰 축으로 다룹니다.
- 계급 진급을 웨이브 클리어에 자동 연결하지 않습니다. 웨이브 외의 성장·진행 방식을 조사하고 있습니다.
- 공격력과 체력 강화는 현재 논의 중인 전투 성장 요소입니다. 스킬, 추가 시스템, 콘텐츠는 후보로 조사하되 아직 확정하지 않았습니다.
- 게임 난도는 접근하기 쉽게 잡습니다.
- 멀티플레이를 염두에 두며, 협동과 대전 중 어떤 형태를 우선할지는 조사 후 함께 정합니다.
- 새 UI/UX나 비바닐라 모델을 Codex가 임의로 디자인하지 않습니다. 그런 자료가 필요하면 실제 외부 사례와 출처를 먼저 찾아 기록합니다.

이 항목들은 사용자가 직접 제시한 방향이며, 세부 규칙과 구현은 열려 있습니다. 기존 맵 작업 지침에 적힌 소형 아레나·기본 유닛·기존 공격/체력 업그레이드 등은 현재 작업 맥락으로만 보관하고, 이 문서에서 새 게임의 확정 설계로 간주하지 않습니다.
