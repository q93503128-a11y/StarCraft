# StarCraft II Arcade Lab

여러 스타크래프트 II 아케이드 모드의 아이디어를 조사하고, 선택한 모드는 별도 프로젝트로 발전시키는 기획 저장소입니다. 현재 해병 성장 RPG는 후보 프로젝트 하나입니다. 이 저장소 전체를 그 게임 하나로 한정하지 않습니다.

## 지금 다루는 범위

- 현재 조사와 신규 아이디어의 대상은 스타크래프트 II입니다.
- 아직 고르지 않은 모드는 `ideas/`에서 한 장짜리 제안으로 비교합니다.
- 구체적인 기획을 시작한 모드는 `projects/<mode-name>/` 아래에 독립 문서와 결정 기록을 둡니다.
- 여러 프로젝트에 재사용할 수 있는 모드 분석과 Galaxy/에디터 제작 사례는 `research/sc2/`에 둡니다.
- 사용자와 합의된 내용만 프로젝트의 결정 기록에 확정 사항으로 적습니다. 아이디어와 조사에서 얻은 시사점은 결정과 구분합니다.
- UI/UX나 바닐라 외 모델이 필요하면 실제 외부 사례를 찾아 출처와 이용 조건을 기록합니다. Codex가 임의로 새 디자인이나 모델을 만들지 않습니다.

## 프로젝트와 후보

- [프로젝트 목록](projects/README.md): 기획 중인 모드의 독립 문서
- [모드 아이디어 보드](ideas/mode-board.md): 서로 다른 플레이 경험 후보와 열린 질문
- [모드 프로젝트 템플릿](templates/mode-project/README.md): 새 아이디어를 프로젝트로 승격할 때 복사할 구조

## 공통 조사

- [스타크래프트 II 모드 사례집](research/sc2/mode-casebook.md): 성장, 협동, 대전, 목표 구성 사례
- [공개 코드·제작 방식](research/sc2/implementation-patterns.md): 공개 맵 코드, 데이터, 액터, Galaxy 패턴
- [외부 시각 자료 원칙](references/README.md): UI·모델·기타 에셋의 출처와 이용 조건
- [기여 및 기획 원칙](CONTRIBUTING.md)

## 같이 기획하는 순서

1. 아이디어 보드에서 모드마다 플레이어 수, 한 판의 핵심 행동, 승리/완료 조건을 한 문장으로 잡습니다.
2. 마음에 드는 후보를 실제 플레이 사례와 구현 사례에 대조하고, 재미·독창성·멀티 적합성·제작량·검증 가능성을 살핍니다.
3. 후보를 선택하면 템플릿으로 독립 프로젝트 브리프를 만들고, 핵심 루프와 첫 플레이 가능한 범위만 먼저 정합니다.
4. 플레이 테스트로 가설을 확인한 뒤 성장, 스킬, 콘텐츠를 늘립니다. 화면이나 모델은 실제 외부 사례를 찾아 출처와 권리를 먼저 확인합니다.

현재의 첫 토론 안은 `해병 성장 RPG`이지만, 다음 모드 후보를 추가하거나 우선순위를 바꿀 수 있습니다.

## 저장소 구조

```text
.
├── README.md
├── CONTRIBUTING.md
├── ideas/                 # 아직 프로젝트로 고르지 않은 모드 후보
├── projects/              # 모드별 독립 기획·결정·회의 기록
├── research/sc2/          # 여러 기획에 공통으로 쓰는 스타2 조사
├── references/            # 외부 UI·모델·에셋 출처와 권리 기록
└── templates/             # 새 모드 기획 시작용 문서 구조
```

저장소에는 기획 문서와 출처만 관리합니다. 맵 소스와 배포 산출물은 별도 개발 공간에 둡니다.
