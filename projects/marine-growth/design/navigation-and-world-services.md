# 목표 안내와 허브 시설 구현 — 2026-10-06

기존 성장·스킬·공유 정찰을 유지하면서 목적지 안내, 의무실, 수송 정산, 행동 취소, 귀환을 한 묶음으로 연결했다. 구현을 모두 마친 뒤 UI를 함께 검사했고, 발견한 두 가지 표기 문제를 한 수정본에 반영했다. 기획 저장소에는 맵 바이너리·개인 Bank를 올리지 않는다.

## 실제 플레이 흐름

- 기본 명령창의 **목표 위치(N)**를 누르면 개인 목적지에 기본 SC2 미니맵 핑을 8초 표시한다. 재사용은 2초다. 이동 명령이나 카메라 이동을 실행하지 않는다. 현재 목적지는 기본 PingObjective 하나를 재사용해 갱신한다. 새 지도 창이나 길찾기 선은 없다.
- 목적지 우선순위는 신청한 허브 시설 → 운반 중인 수송 보급품 → 직접 선택한 탐험 보급품 → 선택/진행 중인 활동 → 참여한 정찰의 다음 대상 → 지역 교신이다. 수송 중 사냥터에서는 복귀 포탈, 허브에서는 보급고를 가리킨다. 허브에서 다른 목적지가 없으면 N을 누를 때만 무기고를 잠시 가리킨다. 죽거나 목적지가 없으면 개인 표식을 제거한다. 시야를 밝히지 않는다.
- 기존 의료선을 **의무실**로 쓴다. 직접 우클릭해 접근하면 비전투 상태에서 2초 치료 후 체력을 완전히 회복한다. 무료이며 단순 접촉으로 치료하지 않는다. 기존 자동 치료 능력은 끈다. 체력이 이미 최대면 필요한 오류만 표시한다. 이동·공격·정지·사망·사냥터 입장은 신청/치료를 취소한다.
- 기존 보급고에서 **운반한 수송 보급품을 직접 우클릭해 정산**한다. 귀환만으로 보상을 지급하지 않는다. 기존 군수·경험치·공적 보상과 개인 90초 재개 대기를 유지한다. 중복 지급을 막으며 지급 실패 때 운반 상태를 남겨 재시도하게 한다. 새 인벤토리는 없다.
- 정지/취소는 개인의 접근·치료·활동 채널을 해제한다. 운반 보급품, 영구 성장, 공유 정찰 참여 자체는 유지한다. 귀환·사망은 기존 개인 정찰 이탈 규칙을 따른다. 스크립트가 내리는 도착 정지와 플레이어가 내리는 정지를 구분해 새 채널을 잘못 취소하지 않게 했다. N과 엄호 같은 순간 능력은 이동 취소로 취급하지 않는다.
- 살아 있는 해병의 일반 귀환과 사냥터 입장이 체력을 몰래 완전히 회복하던 처리를 제거했다. 이동 전 체력을 유지하고 의무실이나 기존 응급처치를 사용한다. 사망 후 구조의 기존 체력 복구는 유지한다. 적 수치·레벨·계급·훈련·저장 형식은 이번에 바꾸지 않았다.

## 화면과 자산

기본 SC2 명령창 N 슬롯, 집결 지점 아이콘, PingObjective/MinimapPing, 기존 목표창과 현장 TextTag, 기존 Medivac/SupplyDepot을 사용했다. 새로운 그림·모델·레이아웃은 만들거나 가져오지 않았다. 시설 표기는 `의무실 · 회복 2초 · 무료`, `보급고 · 수송 정산`으로 필요한 효과만 보여준다. 저장 성공·개발 상태·구현 설명은 추가하지 않았다.

초기 UI 검사에서 N 툴팁의 불필요한 동작 설명과 중립 시설 선택 시 효과 정보가 보이지 않는 문제를 발견했다. 수정본에서 툴팁을 `목적지 표시 · 재사용 2초`로 줄이고 시설 효과를 기존 현장 표기에 넣었다. 최종 실제 캡처에서 두 표기를 다시 읽었으며 겹침 없이 확인했다.
