# 스킬·패시브·진화 실제 구현 — 2026-10-04

[기존 트리 초안](skill-tree-and-evolutions.md)을 정본 Galaxy와 SC2 기본 명령창에 연결했다. 아래는 실제 구현이며 보스·다운·새 직업까지 구현했다는 뜻은 아니다. 최신 사용자 지시에 따라 코드를 전부 연결한 뒤 UI를 묶어 확인했다. 전투 플레이 테스트는 하지 않았다.

## 조작과 훈련

- Q 집중 사격, W 엄호 태세, E 야전 응급처치. 일병에서 기본 3개 기술이 무료로 열린다. 사냥터에서 사용한다. 응급처치는 자기 해병 또는 동료를 대상으로 지정한다.
- G 훈련, V 진화, B 기존 비전투 귀환, Y 기존 카메라 제어. 기본 이동·정지·위치 사수·순찰·공격을 보존했다. 단순 명령창에서는 기본 명령이 SC2 이동/공격 안내로 표시되고 잠긴 액티브는 숨겨질 수 있다.
- G에는 액티브 강화 3개와 패시브 6개가, V에는 기술별 A/B 선택 총 6개가 있다. SC2 기본 명령창의 두 페이지이며 새 대화창·레이아웃·그림을 만들지 않았다. 잠겨 있어도 메뉴를 열어 조건과 효과를 볼 수 있다.
- 훈련·진화 구매는 안전 허브의 무기고 근처에서만 가능하다. 5레벨마다 1점, 최대 50점. 남은 포인트는 레벨과 저장된 투자량에서 계산한다. 중복 지급용 저장 필드는 없다.
- 액티브 II는 1점/병장, III는 추가 2점/중사. 패시브 I/II/III는 1/2/3점, 상병/하사/소위 자격이며 III는 레벨100도 요구한다.
- 첫 진화는 상사·레벨50, 두 번째는 원사·레벨100, 세 번째는 소위·레벨150. 해당 액티브 III와 연결 패시브 I, 4점이 필요하다. A/B 중 하나를 영구 선택한다. 재화·진행 초기화는 없다.
- 전체 노드 완성에 57점이 필요하여 50점으로 전부 채우지는 못한다.

## 액티브와 진화

| 기술 | 기본→II→III | 진화 A | 진화 B |
|---|---|---|---|
| 집중 사격 | 표식6/7/8초, 본인 피해+15/20/25%, 동료+5/5/8%, 대기24초 | 약점 사격: 동료+12% | 연쇄 표적: 처치 후 반경5 적 하나에3초 약한 표식, 본인+12%/동료+4%; 재연쇄하지 않음 |
| 엄호 태세 | 6초, 본인 피해-20/25/30%, 반경5 동료-8/10/12%, 대기28초 | 분대 방벽: 동료-20% | 전진 엄호: 본인-40%, 동료-8%; 이동 가능 |
| 야전 응급처치 | 대상 최대 체력20/25/30% 치료, 대기30초 | 지속 치료:30% 즉시 +5초간 매초2% | 전투 처치:대상25%, 반경5 부상 동료 한 명12% |

초안의 보스 전용 약점 일제사격은 보스가 없는 현재 범위에서 일반 적에게도 유용한 약점 사격으로 적용했다. 다운 시스템을 전제로 한 소생은 현재의 지속 치료로 바꿨다. 다운·보스 자체는 추가하지 않았다.

표식 중첩은 가장 강한 한 효과를 적용한다. 추가 피해는 기본 무기 피해 이벤트에서만 발생하고 별도 NoProc 효과와 재귀 방지로 다시 발동하지 않는다. 연쇄는 같은 지역의 가까운 살아 있는 적 하나로만 넘어간다. 사망/귀환 시 임시 효과를 해제하고 영구 투자와 재사용 대기시간은 보존한다.

## 패시브

| 노드 | I / II / III |
|---|---|
| 표적 분석 | 본인 표식 추가 피해 +2/4/6% |
| 전투 호흡 | 같은 적에게5회 사격 뒤 다음 사격+8/12/16%; 다른 표적 또는6초 공백 시 연속 횟수 해제 |
| 견고한 자세 | 1.5초 정지 후 피해-3/5/7%; 엄호 중 이동하면 절반 효과 |
| 전우 엄호 | 반경5 동료 피해-2/3/4%; 동일 효과는 최댓값 |
| 응급 처치술 | 치료 제공자 또는 대상의 +8/12/16% 중 큰 보너스 하나만 적용 |
| 구조 동선 | 치료·교신·확보 완료 뒤 피해-5/8/10%,4/5/6초 |

구조 동선은 다운/구조 이벤트 대신 현재 있는 치료·현장 활동에 연결했다. 방어 효과는 동일 보호자끼리 최댓값을 쓰고 서로 다른 효과는 곱하며 전체 감소는50%로 제한했다. 낮은 단계가 높은 단계의 지속시간을 연장하지 않는다. 치료·보호 기여자는 같은 지역의 가까운 동료 교전에 참여자로 기록되어 막타 없이 처치 보상을 받을 수 있다. 실제 멀티 동작은 미검증이다.

## 개인 저장

스키마5의27개 필드에 기존15개 +훈련9개 +진화3개를 기록한다. 유효한 스키마1–4는 이전하여 군수·강화·탐험·XP·공적·계급·활동 기록을 보존한다. 서명/소유자/자료형/필드 수/범위뿐 아니라 훈련 예산, 계급·레벨 자격, 진화 선행 조건도 검사한다. 잘못된 프로필은 덮어쓰지 않는다. 메뉴 UI 실행에서 기존 군수1010과 레벨1/이병 상태가 유지되었다. 실제 투자한 스킬의 디스크 재접속은 아직 확인하지 않았다.

## 검증 범위

코드 검사30개 통과. 기존 성장11개에 포인트 예산·구매 중복·단계/진화 자격·불법 저장·혼합 빌드 이전, 대상/거리/지역/쿨다운, 표식 최댓값·연쇄, 여섯 번째 공격·재귀 차단, 보호 중첩/상한/정지, 치료 상한/5회 추가 치료/추가 동료, 낮은 보호의 연장 차단, 귀환 보존·실제 피해 핸들러의 지원 기여를 추가했다. 실제 Galaxy 함수 본문을 native 어댑터로 평가하며 완전한 Galaxy 타입 검사나 엔진 전투 검사는 아니다.

MCP10개 범주 오류0. 경고22개는 기존 번역 키1개와 외부 SC2 기본 아이콘 참조21개다. 설치된 코드 해시가 검사한 코드와 같다. 지형·Objects·MapInfo·미니맵은 이전 정본과 바이트 동일하다.

모든 기능 연결 뒤 기본/훈련/진화 UI를 묶어 검사했다. 기본 명령 인덱스 덮임·툴팁 줄바꿈·잠긴 메뉴의 탐색 자격을 수정했다. 첫 수정 확인에서 추가 탐색 조건을 발견하여 한 번 더 고쳤고 최종 G/V 페이지 접근과 툴팁을 실제 Print Screen으로 확인했다. 요청한 한 번의 수정으로 끝내지는 못했다. 전투·훈련 구매·진화 선택·강제 레벨/재화 지급은 하지 않았다. 모든 UI 실행은 창 메뉴 전체화면이며 실행 전후 정본/실행 복사본 해시가 일치했고 새 ScriptError/Alerts는 없었다.
