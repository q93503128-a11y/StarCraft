# 탐험 보급품과 월드 UX

2026-10-04. 사용자는 밸런스보다 콘텐츠·디자인·UI/UX·재미 요소 구현을 우선하도록 요청했다. 전투 수치는 기본적인 오류·상한만 확인하고 실제 밸런스 조정은 사용자가 나중에 맡는다. 제작자 코드/장면을 확인하며 진행하고 SC2 기본 모델·UI를 사용한다.

## 이번 구현

허브 시작 시야에 외곽·북부 포탈 두 목적지가 모두 보이도록 북부 포탈을56,68로 옮겼다. 기존 외곽56,64는 유지했다. 기본 테란 비콘 두 개로 발밑 위치를 표시한다. 처음56,70은 모델이 화면 위에서 잘려 실제 캡처를 읽고 수정했다. 최종 두 포탈 모델/이름과 북부 우클릭 입장을 확인했다.

사냥만 반복하는 공간에 탐험 보급품6곳과 기본 젤나가 감시탑3곳을 추가했다. 무기고는 여전히 한 곳에서 네 강화를 구매한다. 클래스·보스·인벤토리·복잡한 새 창은 이번 범위에 넣지 않는다.

| 요소 | 행동 | 결과 |
|---|---|---|
| 보급품 | SC2 기본 내려간 보급고를 직접 우클릭해 접근 | 군수50,개인별 지점당 영구1회 |
| 회수 상태 | 같은 지점을 다시 찾음 | 자기 화면에 ‘회수 완료’; 타인의 회수를 막지 않음 |
| 감시탑 | 기본 젤나가 감시탑에 접근 | 기본 점령 애니메이션·넓은 주변 시야·미니맵 표식 |
| 목적지 포탈 | 허브에서 목적지 모델을 우클릭 | 자기 해병만 해당 공유 사냥터로 이동 |

보급품은 접촉만으로 받지 않는다. 우클릭 후 다른 이동/공격 명령을 내리면 회수 접근을 취소한다. 캐릭터가 가까워지면 지급하고 그 지점의 개인 상태를 저장한다. 물체는 남아 다른 플레이어도 자신의 보상을 받을 수 있다. 반복 수령 시 필요한 오류만 표시한다. 게임에는 보상·회수 상태·시설/지역명만 추가하며 개발 설명·저장 성공 알림은 넣지 않는다.

군수50은 임시 기능 수치다. 기존 적HP·피해·보상·강화 비용을 유지했다. 탐험 지점을 더했다고 재미나 경제 완성을 주장하지 않는다.

## 배치

| 지역 | 보급품 지점 | 감시탑 |
|---|---|---|
| 외곽 | (82,73),(84,96),(101,20) | (83,89) |
| 북부 | (96,149),(125,171),(169,156) | (100,155),(162,154) |

기존 길에서 조금 벗어나 발견하고 다음 표식으로 이동하게 배치했다. 감시탑은 기본 미니맵 눈 표식을 사용한다. 기존192×192지형·배치·미니맵 바이너리를 바꾸지 않고 런타임 기본 유닛으로 구현했다. 북부 첫 감시탑의 오른쪽 실루엣에 나무가 조금 겹친다. 나머지 지점의 시야/접근과 지역별 분위기는 후속 화면 검증 대상이다.

## 저장

기존 서명된Schema1프로필의 군수·네 강화·첫 보너스·소유자를 검증한 뒤 그대로 보존한다. Schema2는 개인 보급품 회수6비트인Exploration을 추가한다. 키9개·타입·0~63범위·소유자·서명을 검사한다. 기존Schema1/8키도 검증해 회수0으로 읽고, 능력치 적용 성공 후 새 형식으로 저장한다. 읽기 실패한 기존 파일은 보존하고 쓰기/보급품 회수를 막는다.

실제 기존 군수590/공격3/체력3/방어3/속도2/첫 보너스를 유지한 채Schema2/회수0으로 전환됐다. 북부 보급품 회수 후 회수8을 저장했다. 재실행에서도 군수815와 같은 ‘회수 완료’를 확인했다.815에는 보급품50과 정상 저글링7처치175가 포함된다. 개인 성장 초기화를 하지 않았다.

## 검증 범위

정본에서 실제 포탈 가시성·입장,북부 첫 보급품 우클릭 회수/군수/개인 상태,중복 지급 거부,첫 북부 감시탑 점령/시야,기존 저장 이전과 재실행 회수 상태를 확인했다. 실제PrintScreen을 직접 읽었으며 강제 이동·처치·재화 지급·가속은 사용하지 않았다. 캡처 후 검토를 위해 두 번 일시정지했으므로 사람의 연속 플레이테스트가 아니다.

최종후보MarineGrowing_Exploration_v1,정본SHA-256:0769340b035221cc94e0295356e254d1f890f0941a6a96e0b6c20ff487c585d8. MCP10항목0오류,지형192×192검사통과. 두 탐험 실행에서 정본/런타임 해시가 전후 일치했고 생성된 런타임 오류 로그는 관찰되지 않았다.

모든6지점·3감시탑의 접근,미회수 지점을 그냥 지나치는 시험,회수 접근 취소,6곳완료,잘못된 저장 회귀,실제2인 독립 회수/표시,탑에서 떠난 뒤 시야,사람의 재미/조작감은 검증 전이다. 다음은 기존 공간의 지역별 분위기·갈림길·표식 시야와 남은 탐험 지점의 접근성을 구현/확인한다. 밸런스 조정은 우선순위에서 내린다.
