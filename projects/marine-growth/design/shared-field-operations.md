# 공유 사냥터 연쇄 정찰 구현 — 2026-10-06

기존 교신·수송·확보가 따로 끝나던 흐름에 **교신 복구 → 지정 무리 소탕 → 진지 확보**를 연결했다. 정본에 연결한 실제 코드와 검증 범위를 기록한다. 이전 스킬·성장 구현을 유지하며 기획 저장소에는 맵 바이너리나 개인 저장 파일을 올리지 않는다.

## 플레이 흐름

1. 사냥터 교신 지점을 직접 조작해 기존 3초 교신 복구를 마치면 해당 지역의 공유 정찰이 시작된다. 단순 접촉으로 시작하지 않는다.
2. 해당 경로의 두 적 무리를 소탕한다. 외곽은 기존 저글링 3마리와 히드라 또는 바퀴 2마리, 북부는 기존 두 무리 6마리다. 새 적 종류나 강제 웨이브는 없다.
3. 지정 슬롯마다 한 번만 집계한다. 같은 자리에서 재생성된 적을 반복 처치해 숫자를 채울 수 없다. 해당 정찰에 합류한 해병의 기존 처치 기여가 있고, 같은 사냥터·생존·근처 조건을 충족해야 집계한다. 기존 치료·엄호 기여 공유도 이 처치 기여 규칙을 따른다.
4. 소탕이 끝나면 기존 진지 확보 지점으로 목표가 바뀐다. 정찰 참가자가 확보를 완료하면 기여자별 추가 보상을 지급한다.
5. 다음 정찰은 세 경로 중 다음 경로로 넘어간다. 두 사냥터의 진행·집계·경로 회전은 독립적이다. 다른 지역으로 이동한 해병에게 보상을 지급하지 않는다.

활동을 강제하지 않으며 자유 사냥, 수송, 개인 보급품 탐험은 그대로 가능하다. 별도 제한 시간이나 실패 벌금은 없다. 모든 참가자가 떠나도 해당 판의 공유 진행은 남아 다시 합류할 수 있다. 정찰의 임시 진행은 새 판에 저장하지 않으며 **레벨·계급·강화·훈련·진화·첫 활동 보상 기록은 그대로 영구 저장**한다.

## 합류와 보상

- 정찰 중 교신 지점을 직접 조작하고 가까이 도착하면 합류한다. 기존 교신 재개 대기 중에도 합류할 수 있다. 합류만으로 교신 보상을 다시 받지는 않는다.
- 시작 후 들어온 해병도 지정 적 처치에 기여하거나, 소탕 완료 후 안전한 진지 확보에 3초 연속 참여하면 정찰 기여자로 인정한다. 적이 근처에 있거나 확보 범위를 벗어나면 해당 연속 참여 시간은 쌓이지 않는다.
- 아무 활동도 하지 않은 관전자에게 정찰 보너스를 주지 않는다. 기여자는 완료 시 같은 사냥터에서 살아 있어야 한다. 지정 적 소탕에 기여한 동료는 확보 지점에 모여 있지 않아도 같은 사냥터에 있으면 보너스를 받는다.
- 귀환·사망·지역 이탈 때 개인의 임시 정찰 참여·기여만 해제한다. 기존 영구 재화나 성장 수치를 초기화하지 않는다. 다시 합류해 기여할 수 있다.
- 기존 교신·확보 보상에 더해 외곽 정찰 완료는 군수180·XP360·공적45, 북부는 각각2배다. 현재 두 지역용 임시 수치이며 플레이 시간·난도에 대한 검증 수치가 아니다.
- 지급 실패가 발생하면 공유 완료 상태를 남겨 재시도할 수 있다. 이미 성공한 참가자는 해당 정찰에서 다시 지급하지 않는다. 이 처리는 코드 어댑터 검사로 확인했으며 실제 엔진 실패를 재현하지 않았다.

| 지역 | 경로 | 실제 대상 슬롯 |
|---|---|---|
| 외곽 | 북쪽 숲길 | 3–5 저글링,18–19 히드라 |
| 외곽 | 동쪽 고개 | 12–14 저글링,28–29 바퀴 |
| 외곽 | 남쪽 협곡 | 6–8 저글링,24–25 바퀴 |
| 북부 | 서부 수림 | 33–35 저글링,39–41 히드라 |
| 북부 | 중앙 암석지 | 36–38 저글링,42–44 바퀴 |
| 북부 | 북부 능선 | 57–59 히드라,54–56 바퀴 |

세 경로는 완전히 다른 미션 유형 6개라는 뜻이 아니다. 같은 소탕→확보 구조의 공간·적 조합 변형이다. 기본 피해량·체력·적 수·지형·배치는 바꾸지 않았다.

## 화면과 자산

SC2 기본 목표창에 현재 정찰·처치 수·경로·보상을 표시한다. 목표 설명은 교신 복구 → 잔당 소탕 → 진지 확보로 표시한다. 참가자의 다음 미완료 적 위치, 소탕이 끝나면 확보 지점에 기존 방식의 개인 TextTag를 표시한다. 이 표기는 안개 규칙을 따르므로 미탐험 위치를 미리 밝히지는 않는다. 별도 미니맵 안내 핑이나 새로운 지도 창은 이번에 추가하지 않았다.

교신 지점은 정찰 중 합류 표기로 바뀐다. 허브에 돌아오면 정찰 목표를 숨긴다. 새 대화창·레이아웃·아이콘·그림·모델을 만들거나 외부 파일을 가져오지 않았다. 기존 기본 목표창과 TextTag API를 실제 재사용했다.

## 검증과 한계

- 기존 성장·스킬30개와 새 정찰16개를 합친 실제 Galaxy 함수 본문 어댑터 검사46개 통과. 6경로 대상·같은 필드 조건·생존/거리·중복 처치·중간 합류·참여 시간·관전자 제외·보상 실패 재시도·지역 독립·회전·기존 저장27키 보존을 확인했다.
- MCP 단계별15패치 후 구조 검사10범주 오류0개, 기존 경고22개(기본 자산21, 기존 트리거 번역1). 이 검사는 완전한 Galaxy 타입 검사를 제공하지 않는다.
