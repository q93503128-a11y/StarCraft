# 탐험 갈래길과 지역별 바닥

2026-10-04. 외곽은 밝은 흙길과 숲 속 공터, 북부는 어두운 숲 사이 낡은 포장 구역으로 구분한다. 보급품·감시탑을 찾아갈 이유가 길에서도 보이도록 기존 이동로에 탐험 갈래를 연결했다. 게임에는 새 설명창이나 개발 문구를 추가하지 않았다.

## 구현

| 공간 | 적용 |
|---|---|
| 외곽 보급품 3곳 | 밝은 흙 공터와 기존 길에 연결되는 갈래 |
| 북부 보급품 3곳 | SC2 기본 작은 타일을 흙·풀과 섞은 낡은 바닥, 연결 길 |
| 감시탑 3곳 | 기본 작은 벽돌 바닥과 접근 길 |
| 북부 입구 | 기본 포장 구역에서 흙길로 이어지는 착지 공간 |
| 구조물 주변 수목 | 북부 나무 4그루를 옮겨 보급품·탑의 실루엣 확보 |

연결 갈래는6개,목적지/입구 바닥은10곳이다. 기본 배치101개의ID를 보존했다. 맵192×192,보행 차단·높이·포탈/적/보급품/탑 위치는 그대로다. 미니맵은 기본 에디터에서 실제 지형으로 다시 생성했다. 기존 전투·보상·강화·저장 코드는 변경하지 않았다.

## 실제 참고와 재사용

제작자가 공개한 [Tristram 장면](https://media.forgecdn.net/attachments/160/323/Tristram_2.JPG)을 작업 전에 실제로 보았다. 중앙 이동 공간을 비우고 건축물과 수목을 가장자리에 놓는 구성을 참고했다. 장면 이미지·모델·맵·UI·제작자 스크립트를 가져온 작업은 아니다. Tristram 자체를 플레이한 것도 아니다.

[Blizzard TerrainTexData](https://github.com/SC2Mapster/SC2GameData/blob/master/mods/liberty.sc2mod/base.sc2data/GameData/TerrainTexData.xml)의 로컬 원문 스냅샷에서BelShirDirtLight/DirtDark/SmallTiles/BricksSmall/BricksLarge정의를 읽었다. 현재 팔레트의SC2기본 흙·타일·벽돌 텍스처와 기본 나무를 재사용했다. 새 그림·모델·텍스처를 생성하지 않았다. [기존 감시탑·회수 코드 조사](exploration-and-world-ux.md)는 이번에도 그대로 사용한다.

## 실제 확인

정본에서 정상 포탈 입장과 지면 이동으로 북부 첫 보급품·첫 감시탑에 접근했다. 감시탑의 나무 겹침이 없어졌고,기본 점령 애니메이션과 넓은 시야가 작동했다. 북부 포장 구역·흙 갈래·개인 회수 상태가 실제 화면에 보였다. 비전투B귀환으로 허브에 돌아온 뒤 외곽에 정상 입장했다.

외곽 첫 보급품 옆 지면으로 이동했을 때 군수815/처치0/회수8이 유지됐다. 직접 보급품을 우클릭한 뒤 군수865/처치0/회수9와‘회수 완료’를 확인했다.50은 정확히 보급품 보상이며 처치 보상이 섞이지 않았다. 기존 강화와 첫 보너스를 보존했고 프로필을 초기화하지 않았다.

실제PrintScreen을 읽고 검토를 위해 캡처 후 일시정지했다. 강제 이동·처치·재화 지급·가속을 사용하지 않았다. 사람의 연속 플레이·재미·난도·조작감 검증은 아니다. 나머지4보급품/2탑과 모든 갈래의 보행,실제2인 독립 회수,탑을 떠난 뒤 시야는 검증 전이다.
