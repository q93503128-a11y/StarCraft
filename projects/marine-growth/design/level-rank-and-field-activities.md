# 영구 성장과 사냥터 활동 구현 — 2026-10-04

이번 문서는 외부 시스템 대조 이후 실제 정본 코드에 추가한 범위를 기록한다. 이전 전수 대조와 설계안은 당시 상태의 기록이다. 기획 저장소에는 맵 바이너리와 사용자 Bank를 올리지 않는다.

## 실제 구현

- 영구 레벨: 초기 만렙 250. 누적 경험치로 레벨을 계산하며 출격·귀환·사망 때 초기화하지 않는다. 레벨마다 기본 공격력과 기본 최대 체력의 0.6%를 더한다.
- 공적 진급: 이병부터 대장까지 18계급. 군수와 공적을 구분하며 무기고에서 공적을 내고 진급한다. 상병·하사·원사에서 강화 가능 깊이가 5·7·10단계로 열린다. 원사 이후 계급의 추가 능력 해금은 아직 없다.
- 무기고 여섯 강화: 공격 10, 체력 10, 이동 속도 5, 방어력 6, 공격 속도 10, 체력 재생 10단계. 기존 3단계와 저장값을 보존한다. 목록에는 최종 한도, 구매 가격 또는 필요한 계급을 표시한다.
- 두 공유 사냥터 각각 교신 복구·보급 수송·진지 확보를 배치해 총 6개 활동 지점을 추가했다. 기존 적 60마리/22무리, 탐험 보급품 6곳, 감시탑 3곳을 유지했다.
- 교신 복구는 현장 참여 3초, 진지 확보는 15초. 근처 적이 있으면 진행이 멈춘다. 교신은 참여자의 전투 상태도 확인한다. 공유 완료 뒤 재개 대기 60초.
- 보급 수송은 보급고를 직접 조작해 개인 운반 상태를 얻고 허브로 돌아오면 보상한다. 개인 대기 90초. 사망 시 운반 상태만 해제하고 영구 성장은 유지한다.
- 현장 참여자는 각자 보상한다. 첫 활동 완료는 개인별로 기록하여 경험치 2배와 추가 공적을 한 번 지급한다. 단순 접촉으로 활동을 시작하거나 구매하지 않는다.
- 기존 개인 Bank를 스키마 4로 이전한다. 스키마 1·2·3의 유효한 진행을 보존하고 XP·공적·계급·활동 첫 완료를 추가한다. 소유자·서명·자료형·필드 수·범위를 검사하며 잘못된 프로필을 덮어쓰지 않는다.
- Y 카메라와 비전투 B 귀환을 유지했다. SC2 기본 목표창·유닛 정보창·기존 기본 무기고 대화창을 사용했다.

스킬·패시브 선택, 스킬 진화, 직업, 보스, 장비/인벤토리는 이번 코드에 추가하지 않았다. 사냥터 사건의 연쇄 상태나 Destiny의 영웅 이벤트도 아직 없다.

## 수치 초안

| 항목 | 현재 코드 |
|---|---|
| 다음 레벨 XP | 60 + 3 × (현재 레벨 − 1) |
| 250레벨 누적 XP | 107,568 |
| 이병→대장 공적 합계 | 20,000 |
| 강화 최초 세 가격 | 군수 25 / 35 / 45 |
| 4단계 이후 강화 가격 | 65 + 20 × (현재 단계 − 3) + 5 × (현재 단계 − 3)² |
| 교신 반복 보상, 외곽 | 군수 80 / XP 180 / 공적 25 |
| 수송 반복 보상, 외곽 | 군수 120 / XP 140 / 공적 20 |
| 확보 반복 보상, 외곽 | 군수 100 / XP 250 / 공적 35 |
| 북부 활동 | 외곽의 2배 |
| 활동 첫 완료 | XP 2배, 공적 +15 × 지역 배수 |
| 적 처치 XP | (12 + 8 × 적 종류 인덱스) × 지역 배수 |

북부 2배는 현재 두 지역의 임시 수치다. 많은 후반 지역까지 같은 2배를 유지한다는 뜻은 아니다. 만렙 시간·재미·난도는 실제 측정하지 않았다. 사용자 요청에 따라 이번에는 수치와 코드로 점검했다.

## 확인한 것과 남은 것

실제 Galaxy 함수 본문을 native 어댑터와 함께 평가하는 코드 검사 11개가 통과했다. 전체 XP 경계, 자원 상한, 적용 실패 시 지불/XP 복원, 저장 1–3→4 이전과 잘못된 프로필 차단, 진급 마지막 인덱스, 개인 첫 보상, 두 참가자 보상, 이탈·적 근처 진행 정지, 수송 중복/대기를 확인했다. 이 검사는 실제 엔진·디스크 Bank·멀티 플레이를 대체하지 않는다. API 인자 수 검사도 완전한 Galaxy 타입 검사는 아니다.

MCP 정본 재개방 후 10개 검사 범주에서 오류 0개. 기존 경고 2개는 트리거 이름 번역 누락과 외부 기본 귀환 아이콘 참조다. 사용자 요청에 따라 전투 플레이 테스트 없이 창 메뉴 전체화면에서 허브와 무기고 UI를 짧게 캡처했다. 여섯 강화 줄, 최종 한도, 계급 잠금, 진급 가격이 잘리지 않고 표시되는 것을 실제 이미지를 다시 읽어 확인했다. 활동 현장 배치·진행·재접속·실제 2인·난도·재미는 이번 실행에서 확인하지 않았다.
