# 전초기지 메인 허브

2026-10-04 현재 제작 기준. 해병은 안전한 전초기지에서 시작하고 직접 사냥터에 들어갑니다. 단계별 출격 버튼과 유한 웨이브는 현재 진행 방식에서 제외합니다.

## 공간과 이용 흐름

마을 → 정비 → 공간의 이동 장치 → 공유 사냥터 → 이동 장치로 귀환입니다. 허브와 사냥터는 암석 띠·낮춘 지형·보행 차단으로 분리합니다. 시작부터 전투를 강요하거나 정비 대기시간을 두지 않습니다. 귀환하면 회복하며, 개인의 군수와 강화는 유지합니다. 한 사람의 귀환은 다른 플레이어나 공유 적을 이동·삭제하지 않습니다.

| 장소 | 현재 기능 | 확장 방향 |
|---|---|---|
| 무기고 | 공격·체력·이동 속도·방어력을 한 건물에서 구매 | 공격속도·재생 등 추가 강화도 같은 건물 |
| 의무실 | 귀환 회복 지점의 표식; 현재 별도 구매 없음 | 치료·회복 역할이 생기면 연결 |
| 보급고 | 집결 공간의 표식; 현재 별도 구매 없음 | 보급 기능이 실제로 생길 때 연결 |
| 전초기지 | 안전 허브 중심 표식 | 진급·작전 기능은 구현 시 별도 결정 |
| 이동 장치 | 외곽 사냥터 입장 / 허브 귀환 | 추가 지역과 콘텐츠 진입 |

기능이 없는 건물을 작동하는 서비스처럼 소개하지 않습니다. 강화마다 건물을 늘리지 않습니다. 무기고를 우클릭해 접근하면 기본 SC2 창에서 현재 단계·효과·가격을 보고 구매합니다. 접촉만으로 재화를 쓰지 않습니다. 창을 닫거나 시설에서 멀어지면 구매하지 않습니다.

## 게임 문구 기준

건물 이름, 효과, 가격, 잔액, 획득 보상과 필요한 오류만 표시합니다. “모든 강화는 여기서”, 구현 설명, 개발 진행, 정상 저장 상태, 장황한 시작 안내를 게임 화면에 넣지 않습니다. 개발 기록과 테스트 조건은 문서에 둡니다. 카메라는 자기 해병을 따라가며 Y로 자유 시점과 해병 시점을 전환합니다.

## 협동과 저장

현재 1~4인 슬롯과 개인 해병·강화·재화·입장 상태, 공유 사냥터 구조입니다. 실제 두 클라이언트의 동시 접속은 미검증입니다. 개인 Bank에는 군수, 네 강화, 첫 처치 보너스 사용 여부를 저장합니다. 잘못된 기존 파일은 보존하고 쓰기를 막습니다. 레벨·계급·스킬은 장기 기획이며 아직 저장할 구현 값이 없습니다.

현재 배치·수치·실제 테스트 경계는 [공유 사냥터 제작 기준](spatial-hub-and-hunting-prototype.md), 배포 절차는 [완료 기준](prototype-build-criteria.md), 출처는 [공개 코드 조사](../../../research/sc2/spatial-services-and-upgrade-code.md)를 따릅니다.
