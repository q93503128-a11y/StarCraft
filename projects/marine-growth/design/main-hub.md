# 전초기지 메인 허브

상태: 2026-10-03 사용자가 요청한 안전한 시작·정비·활동 진입 흐름. 전초기지라는 테란 테마와 세부 배치는 위임받은 작업안입니다.

## 플레이 흐름

접속 → 안전한 전초기지 → 성장 투자/정비 → 활동 선택 → 전장 → 보상 확인 → 전초기지 복귀입니다. 맵을 켜자마자 전투를 강요하지 않습니다. 기지에서 기다리거나 설정을 확인해도 적이나 카운트다운이 시작되지 않습니다.

성장 데이터가 생기면 기지에서 프로필을 불러오고 저장 상태를 확인합니다. 복귀는 체력과 전투용 임시 상태를 정비하는 과정이며 레벨·계급·강화·스킬·패시브를 초기화하지 않습니다. 실패/철수는 작전 완수 보상과 구분하되 이미 확정된 영구 성장은 보존합니다.

## 허브의 역할

| 장소 | 장기 역할 | 현재 제작 범위 |
|---|---|---|
| 지휘소 | 작전·탐험·사냥터·이벤트·보스 활동 선택 | 기본 훈련장 출격/복귀만 연결 |
| 정비소 | 체력 회복, 공격/체력 강화 | 복귀 시 체력 회복. 강화 구매는 다음 작업 |
| 훈련/인사 | 진급, 훈련 포인트, 스킬·패시브 투자 | 후속 성장 구현 단계 |
| 집결 구역 | 친구와 만나 공동 출격 | 1~4인 협동 구현 단계 |

건물을 늘리기 위해 서비스마다 별도 동선이나 여러 팝업을 강제하지 않습니다. 해병 한 명으로 돌아다닐 수 있는 작고 읽기 쉬운 기지가 우선입니다. 최초 활동은 하나만 열고 이후 활동 유형을 늘립니다. 일일 입장 제한이나 정비 대기 노가다는 두지 않습니다.

## 활동·협동 확장 경계

장기적으로 같은 허브에서 사냥터, 목표형 작전/탐험, 선택형 보스/이벤트에 접근합니다. 모두 같은 보상 구조와 복귀 흐름을 사용합니다. 친구와 같이 출격할 수 있는 흐름을 우선하며, 한 SC2 맵에서 여러 파티가 독립 전장을 동시에 운영하는 구조는 지역 복제·카메라·플레이어별 트리거의 실제 검증 후 결정합니다. 지금 단일 플레이 훈련장을 그 기능의 구현으로 보지 않습니다.

## 이번 구현과 확인 기준

- 표준 SC2 사령부·공학 연구소·보급고를 기지 표식으로 사용합니다. 현재 건물은 구매/진급 서비스를 제공하지 않습니다.
- 해병 한 명이 안전한 기지에서 시작합니다. 플레이어가 기본 SC2 버튼으로 출격해야 훈련장과 적이 활성화됩니다.
- 복귀는 게임의 정상 이동 기능으로 연결하고 적을 정리한 뒤 체력을 회복합니다. 훈련 완료와 도중 철수의 상태는 구분합니다. 보상은 아직 구현하지 않습니다.
- 시작 대기, 버튼 출격, 일반 전투, 버튼 복귀와 회복을 실제 정본에서 확인합니다. 제목/버튼 가독성도 실제 Print Screen 캡처로 확인합니다.
- 이번 기능은 안전한 허브와 훈련장 왕복만 추가합니다. 보스·인벤토리·새 클래스·복잡한 자체 UI를 함께 구현하지 않습니다.

다음은 기지 정비에 공격/체력 강화와 재화를 연결하고 현재 세 적 유형의 짧은 전투 묶음을 검증하는 작업입니다. 지형·동선의 실제 화면 검토도 이 과정에 포함합니다.
