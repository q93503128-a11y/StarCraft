# 마을 시설과 공유 사냥터 제작 기준

2026-10-04 사용자 수정 반영. 계급·레벨250·영구 성장·스킬 갈래 기획은 유지하며, 현재 제작은 공간과 기본 사냥·구매·저장을 연결하는 단계입니다.

## 실제 구조

안전한 전초기지에서 시작 → 무기고 정비 → 걸어서 이동 장치 이용 → 공유 사냥터 → 직접 이동·공격 → 귀환 장치로 회복합니다. 귀환이나 구조는 다른 사람을 이동시키거나 공유 적을 지우지 않습니다. UI 출격 버튼이나 웨이브 완료가 성장을 강제하지 않습니다.

허브는 28~60×48~82, 사냥터는 72~124×12~116입니다. 중앙 암석 띠, 내려간 지형과 보행 차단으로 단절합니다. 사냥터 면적은 이전보다 약2.45배입니다. 현재 바닥의 재질·길·환경 완성도는 아직 개선 단계입니다. 새 일러스트·모델·직접 만든 시각 디자인은 사용하지 않습니다.

저글링12·히드라6·바퀴6의 24개 생성 지점을 둡니다. 처음 상대할 저글링은 단독으로 두고, 안쪽에는 2~3마리 무리를 배치합니다. 적은 가까운 사냥 중인 해병을 추적하되 생성점에서 너무 멀리 끌려가지 않습니다. 죽은 적은 10초 후 생성하며, 살아 있는 해병이 생성점6칸 안에 있으면 1초씩 미룹니다. 모든 지점의 밀도·전투 난도는 아직 정상 플레이 검증이 필요합니다.

## 한 무기고의 강화

| 항목 | 효과/회 | 현재 단계 | 군수 비용 |
|---|---|---|---|
| 공격 | +2 | 3 | 25/35/45 |
| 최대 체력 | +25 | 3 | 25/35/45 |
| 이동 속도 | +0.35 | 3 | 25/35/45 |
| 방어력 | +1 | 3 | 25/35/45 |

무기고 한 건물을 우클릭해 접근하면 SC2 기본 창에 네 항목이 함께 나옵니다. 단계·효과·가격을 확인하고 해당 구매 버튼을 눌러야 재화가 차감됩니다. 접촉만으로 구매하지 않습니다. 구매 후 잔액·가격·구매 가능 여부를 같은 창에서 갱신합니다. 시설에서 멀어지거나 사냥터에 들어가면 닫힙니다. 비용은 현재 기능 검증 수치이며 250레벨 전체 경제가 아닙니다.

향후 공격속도·체력 재생도 같은 건물에 추가합니다. 사거리·재사용시간은 전투/스킬 구현 이후 상한을 두고 검증합니다. 치명타·흡혈·지원 효과는 선택형 스킬/패시브 갈래로 이어갑니다.

## 표시와 카메라

게임 문구는 건물 이름·효과·가격·보상·필요한 오류만 남깁니다. 정상 저장 상태, “모든 강화는 여기서” 같은 서비스 설명, 개발 진행과 시작 안내는 화면에 넣지 않습니다. 무기고·의무실·보급고처럼 이름만 표시합니다. 의무실과 보급고는 현재 별도 클릭 서비스가 없는 표식입니다. 카메라는 자신의 해병을 추적하며 Y로 자유 시점을 켜거나 다시 고정합니다.

## 보상·협동·저장

기여자는 개인 군수를 받습니다. 저글링25·히드라40·바퀴60, 첫 처치 추가25입니다. 플레이어1~4의 해병·강화·군수·입장 상태는 분리하고 적은 공유합니다. 실제 2인 동시 접속·협동 보상·서로 다른 귀환은 미검증입니다.

Bank에 군수·네 강화·첫 처치 여부를 저장하고 섹션/키 수·타입·버전·소유자·서명·범위를 검사합니다. 읽기 실패하면 기존 파일을 지우지 않고 쓰기를 막습니다. 사전 로딩 누락으로 최초 재실행 시험에서 복원 실패와 시험 프로필 초기화가 관찰됐습니다. 수정본에는 플레이어1~4 BankList를 넣었으며 실제 재검증 결과를 아래에 기록합니다. 레벨/계급/스킬 저장은 구현 전입니다.

## 실제 검증 기록

- 솔로 정상 입장, 저글링 첫 처치 군수50, 전투 후 자발적 포탈 귀환 확인.
- 한 무기고에서 공격0→1(50→25), 체력0→1(25→0), 가격35 갱신과 잔액 부족 비활성 확인.
- 이전 솔로에서 이동 속도·방어력 첫 구매, 체력70 패널 확인.
- Y 잠금/해제/재잠금, 허브 경계 한 지점 보행 차단 확인.
- Bank 파일에 구매 값 기록 확인. 첫 재실행 실패는 통과에서 제외. BankList 추가 뒤 실제 정상 맵 나가기→로그인 화면→재실행에서 군수25와 체력1 복원, 같은 창의 가격35 확인. 복원 잔액으로 공격1 구매까지 확인. 실제 사냥터 해병70/70, 재실행 후 첫 처치 보상25로 첫 보너스 중복 방지 확인.
- 사람의 재미·조작감·장기 성장 시간은 미검증.

외부 사례의 실제 읽은 코드/이미지와 적용 경계는 [공개 코드 조사](../../../research/sc2/spatial-services-and-upgrade-code.md)에 있습니다. 테스트는 정본 설치·재열기·전후 해시·로그·실제 Print Screen을 기록하며, 외부 강제 이동·처치·시간 가속을 사용하지 않습니다.
