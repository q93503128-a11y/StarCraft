## 2026-10-07 수송 경로와 사냥터 순찰

각 공유 사냥터의 보급 수송 지점을 고정 위치 세 곳으로 구성했습니다. 한 번에 한 보급고만 활성화하고, 수송 보상을 받은 뒤 다음 위치로 순환합니다. 이전 지점 근처에 플레이어가 있거나 이동 중이면 전환을 보류해 안내 대상이 갑자기 바뀌지 않게 했습니다. 위치들은 기존 안전 허브와 각 필드 경계 안에 두고, 모델·아이콘·인터랙션은 SupplyDepotLowered와 기존 개인 목표 안내를 재사용합니다.

적은 각 진지 고정 출현점을 중심으로 짧은 네 지점 순찰을 합니다. 외곽과 북부 필드는 서로 반대 방향으로 돌며, 플레이어를 쫓을 때는 기존 진지 반경과 복귀 규칙을 따릅니다. 적 종류·공격력·생성 수·보상 수치는 바꾸지 않았습니다.

장식 사령부의 이름표와 선택 기능을 제거했습니다. 의미 있는 시설만 이름을 표시하고, 의무실·보급고 이름에 붙어 있던 반복 설명은 줄였습니다. 실제 기능·가격·보상·오류만 게임 안에 표시합니다.

## 현재 구현

- 기존 두 공유 사냥터와 교신→지정 무리 소탕→진지 확보 구조를 유지합니다.
- 각 지역의 세 정찰 경로에 고정 확보 비콘 세 곳을 연결했습니다. 두 지역 합계 여섯 후보 지점이며 기존 두 곳에 기본 비콘 네 개를 추가했습니다. 한 지역에서는 한 곳만 활성 시설로 안내합니다.
- 외곽 후보: (104,78), (110,62), (108,35). 북부 후보: (158,161), (141,142), (177,164).
- 경로 번호에 따라 활성 확보 지점을 선택합니다. 기존 지점으로 접근 중이거나 확보 중인 플레이어가 있으면 변경을 미룹니다. 소탕 단계에서 안전해지면 전환하고, 확보 단계에 들어가면 해당 판의 목표를 고정합니다. 바쁜 상태로 소탕을 끝낸 경우 기존 활성 지점에서 마무리할 수 있습니다.
- 유닛을 순간이동시키지 않습니다. 비활성 후보에는 월드 이름표를 달지 않으며 선택을 비활성화합니다. 개인 이름표와 N 목적지는 실제 활성 시설을 따릅니다.
- 조사 목표는 선택·진행 상태에 따라 표시합니다. 정찰·수송·확보 중에는 선택하지 않은 조사 안내를 숨기며, 진행 기록 자체는 보존합니다.
- 확보 진행창이 표시될 때 같은 정찰 마무리 목표를 중복 표시하지 않습니다.
- 사냥터 포탈에서 8.5 거리 이내일 때 가까운 사냥터의 미리보기를 기본 보너스 목표에 표시합니다. 기본 툴팁으로 적 종류와 지역 조사 보상을 읽습니다. 사냥터·무기고·치료·수송 중에는 숨깁니다. 별도 창이나 디자인은 추가하지 않았습니다.
- 활동 시설의 코드상 상세 정보에는 행동 조건, 기본 보상, 첫 완료 추가 보상을 구분해 적었습니다. 기본 비콘의 타깃 불가 속성과 별개로 기능 있는 시설의 선택·타깃·강조 상태를 명시했습니다.

새로운 활동 종류나 새 사냥터를 추가한 것은 아닙니다. 조사 자체는 기존 세 지점 조사이고, 이번 콘텐츠 변화는 정찰 경로의 확보 종착점입니다. 250레벨·18계급·강화6종·훈련/진화·Bank5/27키·적60마리와 전투 수치는 유지합니다.

## 검증 범위

실제 Galaxy 함수 본문을 실행하는 네이티브 어댑터·카탈로그·회귀 검사100개를 통과했습니다. 저장 구조와 마이그레이션, 성장·훈련·진화·보상 중복 방지, 여섯 확보 후보·접근자 보호·활성 목표 안내·개인 목표 표시·미리보기 억제를 포함합니다. 이 검사는 게임 엔진, 동기화, 디스크 Bank 서명을 증명하지 않습니다.

MCP 문서 검사10분류 오류0, 기존 경고23(기본 자산 참조22/이전 번역키1)입니다. 맵40파일 중 Galaxy 한 파일만 바뀌었고 지형·Objects·카탈로그·현지화·MapInfo·미니맵·BankList는 바뀌지 않았습니다. 확보 후보와 접근점의 장애물 중심 거리 검사는 통과했지만 실제 이동 경로·유닛 발자국 검증은 아닙니다.

모든 구현 뒤 실제 게임 Print Screen으로 허브·미리보기 툴팁·외곽 진입·귀환·무기고를 검사했습니다. 중립 포탈 선택으로 상세 정보에 접근할 수 없어 가까운 포탈의 기본 목표 툴팁으로 대체했습니다. 원인을 선택 트리거로 추측했으나 해당 트리거는 시작 시 한 번만 실행됨을 확인해 추측을 폐기했습니다. 원래 시설 상세 패널이 열렸다고 주장하지 않습니다.

정찰 완료, 확보 지점 전환, 실제 조사/수송/치료 보상, 협동, 스킬 전투, 투자 후 재접속과 재미·난도는 이번에 플레이하지 않았습니다. 디버그 이동·강제 처치·성장 가속도 사용하지 않았습니다. 사람의 일반 플레이가 필요합니다.
