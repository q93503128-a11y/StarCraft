# 지역 조사와 협동 활동 구현 — 2026-10-06

두 공유 사냥터에 자유 사냥·수송·정찰 소탕과 별도로 선택하는 **지역 조사**를 연결했다. 개인 조사 기록, 협동 조사 속도, 다음 목적지, 보상·재조사, 이탈·취소·귀환과 기존 진지 확보의 협동 가속을 한 묶음으로 구현했다. 새 지역·보스·직업·장비·인벤토리는 추가하지 않았다.

## 실제 조사 코스

각 사냥터의 세 조사 지점을 직접 우클릭해 접근하고 조사한다. 접촉만으로 시작하지 않는다. 한 지점은 혼자2초, 같은 지점을 함께 조사하는 유효 참가자가 있으면1초다. 자기 채널을 직접 진행해야 자기 기록이 쌓이며 주변 관전자에게 기록·보상을 주지 않는다. 다른 지점에서 조사하는 동료는 속도를 올리지 않는다. 뒤늦게 온 사람에게 이미 끝난 동료의 진행을 복사하지 않는다.

| 사냥터 | 조사 지점 | 최종 위치 |
|---|---|---|
| 외곽 | 숲길 / 감시 구역 / 협곡 | (84,76) / (86,99) / (100,26) |
| 북부 | 진입로 / 암석지 / 동부 수림 | (94,145) / (134,173) / (170,152) |

세 곳을 어떤 순서로 해도 된다. 다른 지점 세 곳을 모두 마치면 군수90·XP240·공적30, 북부는 각각2배를 받는다. 이후 개인별90초 재조사 대기를 둔다. 다음 코스는 추천 시작 지점을 세 곳 사이에서 회전시킨다. **같은 세 지점의 추천 순서를 바꾸는 것이며 완전히 다른 임무 세 종류나 절차 생성 맵은 아니다.** 다른 사람과 다른 사냥터의 기록·재개 시간은 독립적이다. 기존 적 수치·처치 보상은 그대로다.

이미 완료한 지점은 같은 코스에서 중복 집계하지 않는다. 전체 보상 지급 실패 때 세 곳의 완료 기록을 유지하고, 같은 지역 조사 지점을 다시 직접 조작해 접근하면 보상을 재시도한다. 성공한 보상을 다시 지급하지 않으며 자동으로 반복 지급/오류 메시지를 내지 않는다.

조사 중 적이6범위 안에 있거나 개인 비전투 조건을 충족하지 못하면 현재 지점의 연속 조사 시간을 다시 시작한다. 이동·공격·정지·이탈은 채널을 취소한다. 이전에 끝낸 지점은 같은 판 동안 유지한다. 운반 중인 수송 보급품은 먼저 보급고에서 정산한다. 다른 사냥터·사망·저장 쓰기 차단 상태에서는 조사/보상을 진행하지 않는다. 레벨 입장 제한이나 실패 벌금은 없다.

**레벨·계급·강화·훈련·진화·재화는 기존 개인 영구 저장을 유지한다.** 조사 중간 기록·추천 순서·재개 대기는 현재 판의 활동 상태다. 새 판에 이 조사 중간 상태를 이어 저장하는 기능은 추가하지 않았다. 기존 공유 정찰의 중간 상태와 같은 구분이며 영구 성장 초기화는 없다. Bank스키마5/27키 및 기존1–4이전은 그대로다.

## 기존 활동과 연결

- 조사에 직접 참여하면 N 목적지는 선택한 조사 지점, 완료 후 다음 미완료 지점으로 바뀐다. 직접 선택한 기존 보급품/활동과 운반 보급품 목적지는 기존 우선순위를 따른다. 공유 정찰의 교신에 합류하면 안내 초점을 정찰 대상으로 전환하며 조사 기록을 지우지 않는다.
- 귀환 때 개인 조사 채널과 안내 초점은 해제하고 조사 목표를 즉시 숨긴다. 같은 판에 다시 들어오면 해당 지역 조사 기록을 보여준다. 사망·취소는 영구 성장이나 완료한 조사 지점 기록을 깎지 않는다.
- **진지 확보**는 기존 혼자15초를 유지하고 유효 참가자2명 이상이면7.5초로 진행한다. 세 명·네 명이라고 더 짧아지지는 않는다. 지역/생존/거리/저장 자격을 통과한 실제 활동 참가자만 센다. 적이 근처면 기존처럼 멈춘다. 진행을 작업 퍼센트와 참가 인원으로 표시하므로 협동 속도가 바뀌어도 잘못된 실제 시간을 보여주지 않는다. 교신3초, 기존 보상 및 공유 정찰의 개인 기여 규칙은 그대로다.

## 기본 자산과 UI

기존 길의 가지와 가장자리 근처에 **기본 Beacon_TerranSmall6개**를 배치했다. 새 그림·아이콘·모델·레이아웃·창은 없다. 기존 기본 목표창의 보너스 목표 그룹과 개인 TextTag, 이미 구현된 N의 개인 PingObjective를 재사용한다. 지역 조사 진행·다음 지점·재개 시간, 필요한 적 제거/비전투 대기/중복 조작 오류와 보상만 표시한다. 현장 이름은 `진입로 · 조사2초`처럼 짧게 쓴다. 모든 조사 지점에 긴 설명을 항상 띄우지 않고 개인에게 추천하는 지점의 표기만 보여준다.

구현 완료 후 묶음 검사에서 선택 조사가 주 목표에 들어가고 ‘조사’가 반복되는 것을 실제 캡처로 확인했다. 이를 보너스 목표와 짧은 이름으로 바꿨다. 코드 좌표 대조에서는 북부 암석지의 기존 나무 중심과 초기 조사 지점/접근점이1.4/1.3만 떨어져 있었고 외곽 감시 구역은 기존 수송 시설과2.2였다. 두 지점도 같은 수정본에서 옮겼다. 최종 좌표 검사에서 나무/바위 중심과 지점·접근점은2.5이상, 기존 보급품·활동과 지점은3이상이다. **중심 거리 검사로 실제 모델 가림·전체 엔진 길찾기를 증명한 것은 아니다.** 실제 화면으로 확인한 곳은 안전 북부 입구/첫 조사 지점이다. 먼 다섯 곳의 시각 품질/이동 가능성은 미검증이다.
