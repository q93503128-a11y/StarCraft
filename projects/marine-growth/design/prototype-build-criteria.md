## 현재 기능과 검증 경계

| 항목 | 현재 구현 | 실제 확인 / 남은 검증 |
|---|---|---|
| 시작 | 자기 해병 1명, 안전한 전초기지 | 시작 대기와 직접 포탈 입장 확인 |
| 공간 | 암석·낮춘 지형·보행 차단, 별도 사냥터 | 경계 한 지점 우회 차단 확인; 전 구간 검증은 남음 |
| 적 | 저글링 12, 히드라 6, 바퀴 6; 개별 재생성 | 입구 저글링 처치 확인; 모든 배치·무리 난도는 별도 확인 |
| 이동 | 월드 포탈 입장·귀환, 기본 SC2 이동·공격 | 전투 후 자발적 귀환 확인; 강제 외부 이동 사용 안 함 |
| 구매 | 한 무기고에 네 강화, 효과·가격 확인 후 클릭 | 공격·체력 실제 구매와 잔액·행 갱신 확인 |
| 추가 강화 | 이동 속도·방어력 | 이전 버전에서 실제 첫 구매 확인; 공격속도·재생은 미구현 |
| 카메라 | 자기 해병 추적, Y 자유 시점 전환 | 잠금/해제/재잠금과 미니맵 조작 확인 |
| 저장 | 군수·네 강화·첫 보너스; 타입·범위·소유자·서명 검사 | 사전 로딩 누락 수정 뒤 정상 나가기·재실행에서 군수25/체력1 복원 확인; 멀티 저장 미검증 |

| 시각 | SC2 기본 모델과 기본 창 | 실제 Print Screen 확인; 바닥·길의 시각 완성도는 개선 필요 |

사냥터는 52×104이며 이전 48×46보다 약 2.45배입니다. 적은 입구의 단독 저글링에서 내부 무리로 분산합니다. 10초 뒤 재생성을 시도하되 살아 있는 해병이 생성점 6칸 안에 있으면 1초 뒤 다시 확인합니다. 이것은 250레벨 전체 지역이나 적 밀도 완성 기준이 아닙니다.

## 인수 기준

접촉만으로 구매하지 않으며, 적용 실패나 잔액 부족에서 재화를 차감하지 않습니다. 공격·체력·속도·방어는 개인에게 적용합니다. 귀환은 남의 적을 지우지 않습니다. 첫 처치 보너스는 개인당 한 번이며 저장합니다. 일반 적 보상은 저글링25·히드라40·바퀴60, 첫 처치 추가25입니다.

여러 명 독립 입장/귀환, 협동 기여 보상, 인원별 난도, 잘못된 Bank 보존, 최대 단계·연타와 구매 예약 취소는 추가 실제 검증이 필요합니다. UI에는 개발 문구·구현 설명·정상 저장 상태를 표시하지 않습니다.

## 정본과 검증 절차

정본은 `C:\Users\skanya\Documents\StarCraft II\Maps\RPG_Test.SC2Map` 하나입니다. 이전 RPG, 빈 맵, 후보와 백업은 보존합니다. 실행 소스는 `MarineGrowing/MarineGrowing.galaxy`입니다.
