# 레벨 1~100 지역 캠페인 및 콘텐츠 완성 기준

상태: **기획 개정 2026-10-10.** 레벨 1~100은 완결된 초중반 캠페인 구간이며, 최종 성장 구간이 아니다. 사냥만으로 Lv100까지 약 3시간을 목표로 한다. 이는 기획 목표이며 정상 플레이 시간으로 확인된 값은 아니다. 정본 맵에 들어간 현재 콘텐츠는 이 계획을 충족하지 않는다.

## 현재 정본과 목표의 차이

현재 정본은 192×192 단일 맵, 안전 허브, 외곽·북부 사냥 구역, 22개 캠프와 저글링·히드라리스크·바퀴 3종이다. Lv1~50/Lv51~100 레벨 게이트는 있지만, 지역별 퀘스트 사슬·서로 다른 사냥 루프·지역 해금 동선이 구현된 캠페인은 아니다. 레벨 숫자 범위를 만들어 둔 것과 Lv100까지 콘텐츠를 완성한 것은 다르다.

기존 2026-10-07 기록의 250레벨 상한과 “레벨 100 완결 목표” 문구는 **이 문서에서 폐기**한다. 현재 정본 코드에는 여전히 250 상한과 낮은 능력치 계수가 있으므로, 1500 성장 체계가 구현됐다고 말하지 않는다.

둘의 공통 구조는 “넓은 맵에 적만 더 놓기”가 아니다. 지역 허브/이동 지점, 플레이어가 받는 목적, 서로 다른 목표 행동, 다음 지역을 여는 기록이 하나의 경로를 만든다. 이를 사냥 루프에 결합하되, 1회 출격의 주 목표는 하나, 선택 목표는 하나, 현장 사건은 0~1개로 제한해 화면·전투 목표가 서로 싸우지 않게 한다.

## 1~100 지역 경로

각 성장대는 20레벨이며, 지역마다 서로 다른 지형 인상과 전술 규칙 하나를 갖는다. 각 지역은 3개 연결 사냥 구역(진입/중심/위험 지대)으로 나누고, 메인 퀘스트 5단계·지역 계약 3종·탐험 기록 3곳·현장 사건 1종·피날레 1회를 제공한다. 추천 레벨은 안내값이며, 친구 합류를 막는 하드 레벨 제한으로 쓰지 않는다. 메인 퀘스트 해금은 개인별 저장한다.

| 레벨 | 지역 및 구역 연결 | 지역을 구분하는 전투/탐험 방식 | 지역 피날레와 다음 해금 |
|---|---|---|---|
| 1–20 | **변경 외곽**: 착륙장 → 보급로 → 감염 경계 | 낮은 위험의 저글링 무리로 이동/전투를 익힌 뒤, 히드라 사격선과 바퀴 방어 진지를 다른 길목에 배치한다. 안전길과 보급 우회로를 선택한다. | 중계기 2곳을 복구하고 지휘 무리를 정리한다. 정제 시설로 향하는 이동 지점 및 첫 탐험 기록 해금. |
| 21–40 | **폐쇄 정제소**: 펌프 외벽 → 운반 회랑 → 반응로 구역 | 전력 릴레이 순서를 선택해 열린 길을 바꾼다. 짧은 위험 우회로와 긴 안전 경로, 펌프 방어·수리 목표를 교차한다. | 펌프 압력을 낮춘 뒤 반응로를 차단한다. 통신 도시의 침수 진입로 해금. |
| 41–60 | **침수 통신도시**: 침수 거리 → 고가 교차로 → 관제 구역 | 3개 통신 노드가 적 증원 지점/현장 정보에 영향을 준다. 노드를 먼저 무력화할지 교차로를 먼저 확보할지 선택한다. | 관제 송신을 끊고 고립 분대를 구조한다. 화산재 채굴지 이동 지점 해금. |
| 61–80 | **화산재 균열지**: 외곽 채굴장 → 용암 운반로 → 심부 갱도 | 경고 후 잠시 위험해지는 통로와 안전한 측면길을 둔다. 채굴 장비 회수, 잔류 분대 엄호, 열기 순환기 가동을 섞는다. 즉사 피해/반복 대기보다 읽기 쉬운 짧은 위험 창을 쓴다. | 안정 장치 2곳을 작동시키고 심부 방어 편성을 정리한다. 궤도 방어선 착륙 지점 해금. |
| 81–100 | **궤도 방어 외곽**: 착륙장 → 릴레이 띠 → 관제 전초 | 릴레이를 끌수록 이동 가능한 안전 구역이 넓어진다. 순차로 안전하게 전진하거나, 일부 릴레이를 남겨 빠른 경로를 여는 위험/시간 선택을 둔다. | 방어 릴레이를 정지시키고 관제 전초의 지휘 편성을 격파한다. Lv100 캠페인 보상은 중간 이정표이며 101+ 성장 콘텐츠와 지역 지도를 여는 기록을 남긴다. |

세 사냥 구역은 하나의 큰 지형 안에서 걷거나 지역 이동 포탈로 이어진다. 허브는 전투 지형에서 완전히 격리한다. 각 지역 진입은 허브의 용도 있는 기존 이동 시설로 처리한다. 5개 지역이 한 192×192 맵에 몰려 좁아지지 않도록 **지역별 맵/이동 방식**을 우선 검토한다. 별도 맵 로딩과 Bank·협동 인계는 맵 전환 자료/코드 및 MCP 기술 검증 전에는 확정 구현 방식으로 단정하지 않는다. 기술 검증 결과에 따라 넓은 단일 월드의 물리적 분리 구획과 개인 포탈을 대안으로 비교한다.

## 지역별 메인 퀘스트 사슬과 선택 활동

각 지역의 다섯 메인 단계는 아래 순서를 따른다. 같은 목표를 20레벨 내내 반복하지 않고, 지역 고유 규칙을 메인 2~4단계에 나눠 도입한 뒤 피날레에서 조합한다.

| 단계 | 목표 행동 | 완료가 여는 것 |
|---:|---|---|
| 1. 교두보 확보 | 입구의 위협 편성 정리, 통신/관측 장치 작동 | 지역 중앙 길, 기본 사냥 계약 |
| 2. 사냥로 조사 | 서로 다른 적 무리/흔적 2곳 조사. 한 지점은 우회 보상 선택 | 지역 탐험 기록, 주요 지름길 |
| 3. 핵심 시설 임무 | 지역별 목표 규칙(전력·통신·열기·릴레이)을 직접 조작 | 고위험 구역 및 두 번째 계약 |
| 4. 현장 사건 | 구조·수송 보호·중계기 방어 중 지역별 대표 목표 하나 | 피날레 진입 및 지역 보상 |
| 5. 지휘 조우 | 일반 적 무리와 정예 편성을 함께 상대하며 지역 목표를 마무리 | 다음 지역 이동, 개인 첫 완수 보상 |

지역 계약 3종은 “처치 수 채우기”만으로 구성하지 않는다. 각 지역에 (a) 사냥 무리 제거, (b) 현장 장치/수색·회수, (c) 경로 방어/구조/운송 중 서로 다른 두 종류 이상을 둔다. 계약은 같은 필드에서 어느 순서로든 수행 가능하고, 진행 상태는 개인 기록으로 지급한다. 주 목표 보상은 기본 지급, 부가 목표와 위험 선택 보상은 선택적이며, 이를 빼도 다음 지역은 열려야 한다.

### 적 무리 구성

레벨을 올리기 위해 체력만 배율로 높이지 않는다. 구역마다 짧은 무리(경계/순찰), 역할 혼합 무리(근접 압박+원거리 지원+버팀), 목표 방어 무리를 배치한다. 현재 정본의 세 종은 첫 구간 기준일 뿐 Lv100 콘텐츠의 최종 적 목록이 아니다. 레벨 1~100 확장에서는 기존 스톡 SC2 유닛 중 아트/액터를 재사용해 전술 역할을 늘린다. 우선 후보는 저글링(빠른 접근/무리), 히드라리스크(원거리 압박), 바퀴(지속 교전), 맹독충(예고되는 돌진/위험구역), 여왕(지원 표적), 뮤탈리스크(이동 경로 압박)다. 각 타입은 출처·기본 무기/행동·자원 비용·적대 AI의 기본 명령을 확인하고, 한 번에 모두 투입하지 않고 지역별로 1~2개 역할을 소개한다. 고유 모델·새 일러스트·외부 UI는 만들지 않는다.

피날레의 “보스”는 새로운 전용 모델이나 별도 대형 UI를 뜻하지 않는다. 해당 지역에서 이미 학습한 스톡 유닛 혼성 편성, 추가 경계 단계, 목표 상호작용으로 만드는 짧은 지휘 조우다. 지역 마지막 메인 목표에 한 번 배치하고, 반복 보상을 위해서만 계속 강제하지 않는다. 모든 조우는 혼자 진행 가능한 기본 난도를 유지하며 협동은 추가 표적 분담/보너스 목표로 보상한다.

## 진행·성장 기준

- 사냥만으로 Lv1→100 약 3시간을 목표로 하되, 첫 완료 퀘스트/탐험 보상은 별도라 사냥 강제 시간을 더 낮출 수 있다. 지역 간 XP 효율은 상승시키고, 후반 필드를 열어도 초반을 강제로 재파밍하지 않게 한다.
- 레벨 100은 캠페인 1막 종료/중간 성장 이정표다. Lv100 후에도 레벨업·계급·스킬·패시브·무기고 강화를 계속한다. 성장 초기화나 프레스티지는 두지 않는다.
- Lv1500 전후를 장기 후반 구간의 기획 기준으로 잡는다. 이는 사용자 희망에 맞춘 후반 목표점이지 확정 만렙은 아니다. 사용자 승인이 없는 한 레벨 상한을 1500에서 닫지 않는다.
- 레벨 1500 전후의 해병 HP/공격력은 수천 단위 이상이 될 수 있도록 설계한다. 적도 성장대와 역할에 맞춰 대응하지만, 전투를 HP만 많은 적의 장기 타격으로 채우지 않는다. 100레벨 이전은 이 수치 규모를 서두르지 않는다.
- 성장 시기를 1–100 입문/초중반, 101–350 기본 빌드 형성, 351–750 역할·지역 확장, 751–1200 후반 진입, 1201–1500 후반 도전으로 나눈다. 구간별 능력치 계수·적 체력/피해·XP 요구량은 전체 지역과 전투 역할을 작성한 뒤 한 기준표에서 계산한다.
- 현재 코드의 상한 250, 최대 XP 107,568, 레벨당 0.6% 능력치 상승은 상기 목표와 불일치한다. Bank XP 자료형·검증 범위·버전 이행, 능력치 상한/엔진 정수 범위, 공격/HP 적용 값을 함께 설계해 일괄 변경한다. Lv1500만 먼저 코드에 넣지 않는다.

## 사용자 테스트를 한 번에 요청할 시점

현재 단계에서 테스트를 요청하지 않는다. 다음 항목이 정본 후보와 코드로 준비된 뒤, 사용자에게 Lv1~100 전체 경로를 한 번에 테스트해 달라고 요청한다.

1. 허브와 5개 지역의 연결/귀환, 실제 지형 구획, 사냥 동선/지름길/지역 이동이 모두 설치된 상태.
2. 지역당 메인 퀘스트 5단계, 계약 3종, 탐험 3곳, 현장 사건, 피날레가 구현되고 개인 진행·보상·Bank 저장/재접속이 이어짐.
3. 지역별 적 무리 편성/종류가 시각·전투 역할상 구별되고, 목적에 필요한 스톡 모델/효과/UI가 실제 화면에서 확인됨.
4. 1~100 권장 성장 흐름과 100 이후 Lv1500 확장에 필요한 저장/수치 구조가 일관됨.
5. 버그 정적 검사와 SC2 로드/화면 캡처 점검을 마치고, 검증 경계와 미검증 사항을 기록함.

밸런스 체감·재미·조작감은 정상 플레이 증거가 생길 때까지 미확인으로 둔다. 한두 시스템만 넣은 중간 후보를 사용자에게 반복 플레이시키지 않는다.

## 조사와 구현 기록 규칙

실질적인 지역/퀘스트/사냥터 배치 전, SC2 모드 두 가지 이상에서 해당 작업과 직접 맞닿은 실제 플레이 구조나 제작자 코드를 다시 확인한다. 작업 기록은 출처의 구체 콘텐츠 → 선택한 요소 → 우리 맵 적용 → 정적/엔진/사람 테스트 범위 순으로 쓴다. 코드를 가져올 경우 출처 라이선스가 허용하는 범위와 수정 여부를 적는다. 이 문서의 외부 두 사례는 문서 조사 근거이며 외부 코드·맵·에셋을 가져온 기록이 아니다.
