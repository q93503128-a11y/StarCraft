# 2026-10-10 적 추적 수정 이어가기

사용자는 앞서 여러 번 외부 모드의 실제 게임 방식·콘텐츠와 제작자 코드를 조사해 융합하라고 지시했고, 매 대화 시작 시 기획 문서를 다시 읽고 다음 대화에도 재독 지시를 남기라고 했다. 오늘 정본과 현재 제작자 코드/가이드를 다시 대조한 뒤 적이 해병을 공격하지 않던 구체 코드를 수정했다.

정본의 기존 스폰 명령은 적을 필드 중앙으로 공격 이동시켰고 주기적 실제 플레이어 표적 선택이 없었다. UA3의 고정 소스는 적 무리를 유효한 생존자 방향으로 공유 공격시키며, Crash RPG의 고정 소스는 생성지 주변 waypoint를 사용한다. 현재 코드는 같은 사냥터 안의 유효 해병을 감지거리에서 골라 기본 공격 명령으로 추적하고, 같은 캠프 적은 표적을 공유하며, 표적을 잃으면 각자 생성지로 복귀한다. 공개 코드 원문은 복사하지 않았다. The Cave의 여러 퀘스트 개방 tele-pad 지역/던전 귀환 포탈과 Legends of the Void의 지역별 임무 완료 후 다음 지역 진출도 다시 대조했다. 아직 우리 정본은 이보다 좁은 단일 맵/두 사냥 구역이며, 그 폭의 콘텐츠는 구현되지 않았다.

스테이징 코드 어댑터 4개, MCP 문법 검사, 10개 범주 문서 검증을 통과했다. 후보 설치 백업, canonical MCP 재개방, full-screen windowed 모드 구동과 실행 전후 해시 검사를 끝냈다. 해시/출처/실제 테스트 경계는 [적 추적 참고 대조](../design/enemy-response-reference-review.md)에 기록했다. 사용자가 정상 전투를 확인할 수 있게 정본을 열어 둔다. 이번에는 게임 입력, 캡처, 전투·시체·멀티플레이 체감 테스트를 하지 않았다.
