# 사냥 중심 성장 전환 — 2026-10-11

## 사용자 피드백과 현재 사실

사용자가 반복 임무식 진행이 불쾌하고, 메이플처럼 사냥터에서 계속 사냥해 강해지는 흐름도 괜찮다고 했다. 임무 중심으로 콘텐츠를 밀지 말고 사냥터를 중심으로 다시 설계한다.

구현 현황을 분리해 기록한다.

- 정본: 외곽/북부 사냥 구역 2곳, 저글링·히드라리스크·바퀴 3종, 캠프 22개. 이번 대화에서 적 종류·사냥터 수는 0 증가했다.
- 이전 스테이징: 개인 임무 단계를 10개에서 15개로 늘렸다. 이 변경은 기존 지역/적/활동 재사용이며 정본에 설치되지 않았다.
- 즉, 임무 분량만 늘었고 실제 사냥 콘텐츠의 밀도·종류는 늘지 않았다. 사용자가 문제 삼은 방향이 맞다.

## 외부 대조와 배운 점

- [Legends of the Void 제작자 소개](https://us.forums.blizzard.com/en/sc2/t/legends-of-the-void-rpg-official/329)는 1~5인, 지역마다 복수 임무를 마치면 다음 구역으로 진입하는 임무 중심 RPG다. 이 사례를 따라 임무 개수를 늘리는 방식은 현재 사용자가 원하는 반복 사냥형 성장과 맞지 않는다. 해당 모드 소개만으로 사냥 필드 루프를 조사했다고 볼 수 없다.
- [Crash RPG 고정 revision MapScript](https://raw.githubusercontent.com/Alzarath/Crash-RPG/c83cbb612affb3d62d3a05eb479521bbb648e570/CrashRPG.SC2Map/MapScript.galaxy)는 목표 상태·카운터 처리의 코드 참고일 뿐, 사냥터 콘텐츠 참고가 아니다. 외부 코드를 반입하지 않았다.
- [메이플스토리 공식 레벨업 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/377)는 레벨에 맞는 사냥터 안내와 필드 사냥을 성장 방법으로 둔다. [공식 사냥 콘텐츠 안내](https://gi.maplestory.nexon.com/Guide/Contents/FieldHunt)는 사냥 중 돌발 미션, 버닝 필드, 엘리트 몬스터 등의 보조 변주를 소개한다. 여기서 얻는 시사점은 일반 사냥이 기본 루프이고, 임무/사건은 사냥을 대체하는 필수 연쇄가 아니라 필드 안의 선택적 변주가 될 수 있다는 점이다.

## 새 작업 기준

1. 레벨·계급·강화 등 지속 성장의 기본 재료는 일반 필드 사냥으로 얻는다.
2. 연속 임무 완료를 성장의 필수 관문으로 두지 않는다. 남기는 임무는 짧은 소개/선택 보상/필드 내 변주로 제한한다.
3. 다음 사냥터는 단순 적 체력 증가판으로 만들지 않는다. 무리 조합, 배치와 길, 적 접근 방식, 사냥 효율, 선택 위험·보상을 서로 구별한다.
4. 본격적인 사냥 콘텐츠 확장 전, 사냥 필드 구조가 드러나는 SC2 제작자 자료/코드/실제 장면 두 가지 이상을 다시 조사해 각각의 실제 플레이 패턴과 적용 가능 부분을 기록한다. 임무 시스템 출처를 사냥 루프 출처처럼 쓰지 않는다.
5. 현재 정본의 세 적 종류와 두 필드는 프로토타입 한계다. 더 큰 적/지역 로스터는 관련 출처와 현재 지도·기술 제약을 비교한 뒤 일괄 확장한다. 이번 턴에는 맵 코드를 변경하지 않는다.
