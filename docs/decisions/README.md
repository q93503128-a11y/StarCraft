# 결정 기록

이 디렉터리는 사용자와 합의된 기획만 기록합니다. 조사에서 발견한 기능은 합의되기 전까지 결정이 아닙니다.

## 합의된 방향 (2026-10-03)

1. 스타크래프트 II만 대상으로 조사하고 기획합니다.
2. 해병의 성장 게임이며 계급은 주요 성장 축 중 하나입니다.
3. 계급 진급을 웨이브 클리어에 매번 고정하지 않습니다. 웨이브 외의 진행 방식을 조사합니다.
4. 난도는 지나치게 높이지 않습니다.
5. 협동 또는 대전 멀티플레이를 고려합니다. 어느 형태를 우선할지는 미정입니다.
6. 스킬·시스템·콘텐츠가 풍부한 방향을 선호하지만 첫 버전 범위는 미정입니다.
7. Codex는 새 UI/UX와 바닐라 외 모델을 임의로 만들지 않습니다. 필요하면 외부 사례와 출처부터 조사합니다.

## 열려 있는 결정

- 계급이 세션 안에서 오르는지, 여러 세션에 걸친 커리어인지
- 계급 성장에 경험치·목표·자원 중 무엇을 쓰는지
- 웨이브 대신 사용할 핵심 진행 루프
- 협동과 대전 중 첫 구현 우선순위
- 공격·체력 외에 어떤 스킬이나 시스템을 첫 범위에 포함할지
- 바닐라 UI에서 어떤 기존 화면/기능을 사용할지

세부 선택이 합의되면 날짜와 근거를 적은 별도 Markdown 결정문을 추가합니다.
