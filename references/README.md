# 외부 시각·에셋 참고

이 디렉터리에는 실제 외부 UI/UX, 바닐라 외 모델, 텍스처, 사운드 등의 출처와 라이선스 조사 결과만 기록합니다. 허가를 확인하지 않은 원본 파일은 저장소에 넣지 않습니다.

자료를 제안할 때 기록할 항목:

- 실제 작품/맵과 제작자
- 화면 또는 에셋의 직접 링크
- 무엇을 참고하려는지 (레이아웃, 상호작용, 캐릭터 모델 등)
- 라이선스/재사용 허용 여부와 확인 날짜
- 게임 내 화면을 실제로 확인했는지

Codex가 사용자의 요청 없이 새 UI/UX 시안이나 비바닐라 캐릭터 모델을 만들지 않습니다. 현재 채택된 시각 자료는 없습니다.
