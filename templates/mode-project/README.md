# 새 모드 프로젝트 템플릿

이 폴더를 `projects/<짧은-모드-이름>/`으로 복사해 새 프로젝트를 시작합니다. 먼저 `design/brief.md`를 채우고, 조사 사실과 합의된 결정을 별도로 기록합니다.

## 프로젝트 문서

- `design/brief.md`: 플레이어 경험, 핵심 루프, 승리/완료 조건, 범위, 열린 질문
- `decisions/README.md`: 합의된 결정만 기록
- `meetings/README.md`: 기획 논의 기록

공통 리서치를 복사하지 말고 저장소의 `research/sc2/`를 참조합니다. 프로젝트 고유 사례가 필요하면 근거와 함께 별도 문서를 추가합니다.
